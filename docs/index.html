کنسول وب AI — Claude Code و Codex در مرورگر

وب‌اپ متن‌باز برای اجرای Claude Code CLI و Codex CLI داخل مرورگر — با رابط فارسی و نمایش بی‌نقص متن مختلط. Open-source, local-first web UI for Claude Code & Codex CLI with a Persian (RTL) interface.

⭐ دریافت از GitHub 📖 مستندات کامل

✨ امکانات / Features

  • کشف خودکار سشن‌های واقعی Claude و Codex از دیسک — حتی سشن‌هایی که از ترمینال ساخته‌اید
  • نوبت‌های پس‌زمینه: جابه‌جایی بین گفتگوها کار در حال اجرا را قطع نمی‌کند
  • صف پیام قابل ویرایش + توقف هر لحظه
  • فورک سشن (شاخه‌زدن گفتگو حتی تا یک پاسخ مشخص)
  • جستجوی متنی در همه‌ی ترنسکریپت‌ها با نرمال‌سازی فارسی/عربی (ي→ی، ك→ک)
  • کشف زنده‌ی لیست مدل‌های Codex + انتخاب مدل و میزان استدلال
  • نمایش مصرف توکن، ظرفیت زمینه و آمار گفتگو
  • فارسی‌نویسی بی‌نقص: جهتِ هر پاراگراف جدا تشخیص داده می‌شود؛ بلاک کد همیشه چپ‌به‌راست
  • اجرای کاملاً محلی روی 127.0.0.1 — کانفیگ و لاگین CLI خودتان بدون تغییر

🚀 شروع سریع / Quick Start

git clone https://github.com/hakbari435/ai-web-console.git
cd ai-web-console
npm install
npm start    # → http://127.0.0.1:3000

پیش‌نیاز: Node.js 18+ و Claude Code و/یا Codex CLI نصب و لاگین‌شده. روی ویندوز فقط run.bat را دابل‌کلیک کنید.
